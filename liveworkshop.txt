title=PhunLewt Reducer
description=This is a B41/B42 mod designed to allow admins to reduce the probability of loot spawning (and respawning) in containers depending on admin defined areas.
description=
description=To illustrate, say I want to reduce the global spawning of ammo by 50%, except I don't want any ammo spawning in Rosewood and I want normal spawning in Louisville. To do this I would:
description=[list]
description=[*]Set the [b]Default[/b] zone for [i]ammo[/i] to 50 (to reduce the global respawn of all ammo by 50%)
description=[*]Set the [i]ammo[/i] rate for [b]Rosewood[/b] to 100 (to reduce respawn by 100%)
description=[*]Set the [i]ammo[/i] rate for [b]Louisville[/b] to 0 (to reduce respawn by 0%, effectively overwriting the default setting)
description=[/list]
description=
description=[H1]IMPORTANT[/H1]
description=
description=This mod can only reduce the item quantities in a container after the game has stocked the container. If the game doesnt stock/restock the container (depending on your settings), this code will not run for that container!
description=
description=This mod Requires the PhunZone and PhunLib mods
description=
description=[H1]Quick Start[/H1]
description=
description=Right click in the world and choose PhunZones from the menu (you must be in Admin mode), then select the region you wish to change (the [b]Default[/b] region is where you edit the "global" values). Click "Edit Region" and scroll to the bottom of the settings window to click the Lewt button.
description=[img]https://i.imgur.com/xaF4Db2.png[/img]
description=Choose the items and/or categories by clicking the "[b]Edit Item Selection[/b]" button.
description=
description=Find the item and/or category of items you wish to change. Double click to adjust. Use a whole number between 0 and 100. 0 will not reduce the item (or category), effectively making it behave as normal (this is so you can override a parent zone, eg the Default zone). 10 will reduce respawn by 10% and 100 will reduce the spawn rate 100% (in other words, it won't spawn)
description=[img]https://i.imgur.com/C604Chi.png[/img]
description=then click OK to save
description=
description=Other settings per zone:
description=[list]
description=[*][b]Hours Till Full[/b]. This is the amount of hours that need to pass until your reduction comes into full effect. For example, lets say you have Aviator Glasses set to 50 and you set this value to 240 (10 game days). For the first hour, the spawn rate will be unchanged, however by day 5, the effective reduction of the glasses will be 25%. Finally, by day 10, the full reduction will take effect (in this case, -50%).
description=[*][b]On Empty Add Item[/b]: In instances where everything in the container gets removed after a restock, add this item. This can at least give a visual cue to a player that the container in fact restocked. It needs to be the full name, eg PhunLewt.Dust or Base.Money
description=[*][b]Inherit[/b]. Untick if you want this zone to ignore any parent or default values.
description=[/list]
description=Sandbox settings:
description=[list]
description=[*][b]Default Reduction[/b]. Reduce all loot spawns by this percentage unless otherwise specified in the zones settings. Requires restart if changed.
description=[*][b]Debug[/b]: Tick this box to see verbose feedback when PhunLewt is removing stuff from containers. Requires restart.
description=[/list]
