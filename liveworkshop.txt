description=
description=This version improves on the original with:
description=[list]
description=[*]Instead of setting all the values per zone, you now create a configuration that you apply to a zone. This allows for easy setup and reuse
description=[*]Inherit other configs to make changes easier
description=[*]Overall, it is just miles better than the previous version
description=[/list]
description=
description=[h1]IMPORTANT[/h1]
description=[list]
description=[*]This mod only reduces loot when the game spawns or respawns items in a container.
description=[*]It will not reduce loot in containers that are baked into the map (many custom maps ship with loot already in containers). However it will apply once those containers restock (if the map supports it).
description=[*]It cannot force loot to respawn in custom maps that are missing or have broken forage zones. Basically if the game won't restock the container, this mod won't be able to change that
description=[/list]
description=
description=[h1]Quick Start[/h1]
description=It is best to start with a [b]Global Default Configuration[/b]. These values apply anywhere no other configuration exists.
description=
description=[img]https://i.ibb.co/B2H4wnDj/pl-default1.png[/img]
description=[list]
description=[*]Open the [b]PhunLewt[/b] editor from the Admin or Debug menu
description=[*]Click [b]New[/b] and give your configuration a name
description=[/list]
description=[img]https://i.ibb.co/0RTrgY57/pl-default2.png[/img]
description=[list]
description=[*]Double-click any item or category and set the percentage to reduce respawn by (e.g. 10 = 10% reduction)
description=[*]When done, click [b]OK[/b] to save
description=[/list]
description=[img]https://i.ibb.co/xSdvrdTM/pl-default3.png[/img]
description=[list]
description=[*]Now open [b]PhunZones[/b] from the Admin or Debug menu
description=[*]Select [i]- Defaults -[/i] (first entry) and click [b]Edit Region[/b]
description=[*]Scroll to the bottom, find [b]Lewt Config[/b], and select your new configuration
description=[/list]
description=Any changes to this configuration now apply globally.
description=
description=[h1]Configuration Settings[/h1]
description=
description=[img]https://i.ibb.co/HfPcmbyp/pl-inherit.png[/img]
description=
description=[table]
description=[tr][th]Setting[/th][th]Description[/th][/tr]
description=[tr][td][b]Name[/b][/td][td]Unique name for this configuration.[/td][/tr]
description=[tr][td][b]Default[/b][/td][td]Applies to all categories not explicitly defined here or in inherited configs. Leave blank to ignore.[/td][/tr]
description=[tr][td][b]Hours Till Full[/b][/td][td]How long (in in-game hours) it takes for the full reduction to apply. Example: if Aviator Glasses are set to 50% and this is 240 hours (10 game days), the reduction ramps from 0% → 50% over that time.[/td][/tr]
description=[tr][td][b]On Empty Add Item[/b][/td][td]If a restocked container ends up empty, this item is added as a visual cue that a restock occurred.[/td][/tr]
description=[tr][td][b]Inherit[/b][/td][td]Inherit values from another configuration (and its parents). Usually, you’ll want to inherit from your Global Default config.[/td][/tr]
description=[/table]
